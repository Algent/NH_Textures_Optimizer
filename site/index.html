NH Textures Optimizer

Lossless PNG optimisation for GTNH textures, using oxipng. Everything runs in your browser and nothing is uploaded.

Drop PNGs, a .zip or a folder here A single PNG is returned as a PNG. Anything else is returned as a zip with the same folder structure, and non-PNG files are kept unchanged.
